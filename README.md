# Autonomous Rover
building an autonimous yard robot to help with outdoor tasks.

![Spyker KAT 2X Chassis_1600x1600](https://github.com/user-attachments/assets/ad6749ae-650d-42da-8ccd-fc320c9697a0)

i am starting this project with a 3d printed kit from spyker workshop the rover will be around 5th scale RC sized ( 3ft by 2ft) powered by 51.2vdc with around 60-100ah

current state of things, lots of 3d printing! 
i am printing the kit in ABS with 100% infill for both strength and weight.
